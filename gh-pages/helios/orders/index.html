Design notes

      
    
        
  • Why a filter on the wheel. A plain wheel keeps selling puts into a falling market and ends up writing calls below cost. The filter stops new puts and sells shares while the trend is down.
    • 
        
  • Only resolvable tokens. otm:1 and 5DTE+ need only listed strikes. delta:30 and mid need a chain snapshot Robin does not have yet.
    • 
        
  • Fail loudly. Stale LSEG data or an unreadable positions.json stops the job before any order file is written.
    • 
        
  • Idempotent ids. nvda-csp-2026-11-23: step plus session date, so a rerun cannot fill twice.
    • 
        
  • Both paths. Same file at open_orders.json (assignment) and mkt/open_orders.json (Sanji spec).
    • 
        
  • Prices on Luffy. NVDA (conid 4815747) is tracked in price_history.json so Sanji has bars to fill against.
